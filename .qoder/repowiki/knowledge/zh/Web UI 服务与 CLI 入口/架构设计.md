模块由两个并列的对外入口组成：
- `web/server.py`：定义 FastAPI `app`，挂载 CORS 中间件、注册 `routes.router`，并通过 `StaticFiles(directory=static/, html=True)` 将 `web/static/index.html` 作为 SPA 根路径暴露；`run()` 通过延迟导入 uvicorn 启动。
- `web/routes.py`：以 `APIRouter(prefix="/api")` 声明三个 REST 端点——`POST /api/analyze`（接收 `UploadFile`，写入临时文件并解码为 `AudioData`，缓存于进程内 `_file_cache` 字典避免重复解码）、`GET /api/spectrogram/{file_id}`（scipy STFT → dB 量化 → Plotly 可用数组）、`GET /api/waveform/{file_id}`（下采样波形）。所有业务逻辑依赖 `..core.*` 子包，不直接操作磁盘。
- `cli.py`：Typer 应用 `hifi-detect`，实现 `analyze`（单文件 + Rich 表格报告）、`batch`（目录扫描 + JSON/文本输出）、`web`（转发到 `web.server.run` 并可选自动打开浏览器）三个命令，复用与 Web 完全相同的 core 分析管线。
依赖方向：`web/*` 和 `cli.py` 均单向依赖 `hifi_detector.core.*`，彼此互不引用，形成“前端/CLI 展示层 → core 计算层”的清晰分层。
