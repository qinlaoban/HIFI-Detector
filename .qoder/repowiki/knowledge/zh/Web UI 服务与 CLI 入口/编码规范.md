- 核心分析函数（extract_metadata / analyze_quality / analyze_loudness / analyze_dynamic_range / analyze_authenticity）在 CLI 与 Web 路由中按相同顺序调用，保证结果结构一致。
- 大对象（已解码的 AudioData 及其临时文件路径）以 `file_id -> (AudioData, Path)` 形式缓存在模块级 `_file_cache` 字典中，后续 `/spectrogram` 与 `/waveform` 通过 `file_id` 查询复用。
- HTTP 错误统一通过 FastAPI 的 `HTTPException(status_code, detail)` 抛出，客户端侧用 JSONResponse 返回结构化字段而非纯文本。
- CLI 中的判定逻辑（clipping / true peak / DR / authenticity）在 `analyze` 与 `batch` 命令中采用相同的阈值分支，确保终端与 Web 的 verdict 语义一致。
