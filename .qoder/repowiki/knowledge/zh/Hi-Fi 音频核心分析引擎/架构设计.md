模块以 `audio_io.AudioData`（dataclass）为唯一输入契约，各分析子模块仅依赖它，形成单向依赖：`authenticity.py` / `dynamic_range.py` / `loudness.py` / `metadata.py` / `quality.py` → `audio_io.py`；`__init__.py` 为空，不暴露包级 API。

- `audio_io.py`：基于 soundfile 的统一解码入口，将任意格式读为 float64、shape `(channels, n_samples)`、归一化到 [-1,1]，并附带 bit_depth/format/subtype 等元信息。
- `authenticity.py`：实现三大伪造检测——频谱截止（Welch PSD + Savitzky-Golay 平滑 + dB/kHz 梯度阈值）、上采样检测（CD Nyquist 以上能量比 + 插值噪声斜率拟合）、假 24-bit（残差功率 + 16-bit 网格对齐 + LSB-8 熵），输出 `AuthenticityReport`。
- `dynamic_range.py`：按 Pleasurize DR14 规范分 0.5s 窗口取 RMS top 20% 做功率平均，输出整数 DR 及边界风险告警。
- `loudness.py`：依 ITU-R BS.1770 实现 K-weighting 双 IIR 滤波、4x 过采样 True Peak、两级门限 Integrated LUFS 与 EBU R128 LRA。
- `quality.py`：裁剪/直流偏移/声道平衡/有效位深估计等基础指标。
- `metadata.py`：从 `AudioData` 派生文件大小、时长显示、估算码率与 subtype_info。

所有算法均为非破坏性、在频域或统计域完成，无外部状态，可独立测试。
